Pibuz

A headless Qobuz Connect endpoint for a Raspberry Pi. Bit-perfect, one binary, appears in the official Qobuz apps like any hardware streamer.

Install or upgrade

curl -fsSL https://philipvinc.github.io/pibuz/install.sh | sudo sh

Installs pibuz @VERSION@ over whatever is on your PATH (or into /usr/local/bin) and reboots. Re-run it to upgrade.

On moOde that is all it does — moOde starts the daemon itself, so no service is installed and Renderer Config stays in charge. A first install on moOde belongs in Renderer Config → Qobuz Connect. Anywhere else it also writes and enables a systemd unit, so pibuz comes up at boot.

Options

curl -fsSL https://philipvinc.github.io/pibuz/install.sh | sudo sh -s -- --no-reboot
                                                              --version 2.4.0
                                                              --user pi
                                                              --standalone

What it needs

  • A 64-bit Linux box — moOde 10.x is what it is tested on; any aarch64 or amd64 Debian works.
  • A DAC. Run pibuz setup once to pick it, or let it take the default.
  • No Qobuz login on the box: you cast to it from the Qobuz app, so any account in the house can.

Then

pibuz status      # is it up, what is it playing, what is the buffer doing
pibuz setup       # pick the DAC, name the device
pibuz settings    # everything else
